Privacy note

This site counts visits so I can see whether anyone reads it. That's the whole purpose: no ads, no profiles, nothing sold or shared.

What is collected

Visits are measured with Azure Application Insights (Microsoft), running in my own Azure subscription. The script is served from this site, not a third-party CDN. For each page you open it records:

  • the page title and path (query strings and #fragments are stripped before sending)
  • the referring page, origin and path only
  • browser, operating system and device type, and how long the page took to load
  • an approximate country / region / city, which Azure derives from your IP address and then discards: the stored IP is 0.0.0.0
  • JavaScript errors, so I can fix broken pages

It does not record anything you type (including the résumé request form), clicks, scrolling, or your full IP address. The admin area is never tracked.

Cookies

  • ai_user: a random ID so repeat visits count as one visitor. Kept for up to one year.
  • ai_session: a random ID grouping pages into one visit. Ends after 30 minutes of inactivity or 24 hours.

Neither contains personal information, and neither is linked to your name or email. Clearing your cookies resets them. Dismissing the cookie notice is remembered in your browser's local storage (cookie-notice-dismissed), not a cookie.

Opting out: Global Privacy Control and Do Not Track

If your browser sends Global Privacy Control or Do Not Track, the analytics script never loads: no cookies are set and nothing is sent. Blocking the script or the cookies with your browser or an extension works too; the site works the same either way.

Automated browsers and known bots and crawlers are also excluded, so the numbers reflect people.

Retention and access

Telemetry is stored in Azure (Log Analytics) for 30 days and then deleted automatically. Only I can read it. To ask about or delete anything, email Colin.shanahan1@gmail.com.

Résumé requests you submit are a separate thing: they are stored only to process the request, and the architecture page shows how that flow works.
